# Claims and evidence

Every claim in the README maps to a test, a bench script or a CI job. `scripts/check_baseline.py`
fails if a backticked reference below points at a file, test function or CI job that does not
exist. Local commands run offline; rows marked **CI** are verified only in GitHub Actions.
